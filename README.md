# 星愿：一箭又一箭

使用 Python 标准库 Tkinter 开发的点击式箭头解谜小游戏。玩家需要观察箭头方向和阻挡关系，按照正确顺序点击，使所有箭头飞出棋盘。

## 功能

- 开始界面、游戏界面、通关与失败界面
- 上、下、左、右四种箭头
- 同行/同列路径阻挡检测
- 飞出动画、碰撞晃动和变色反馈
- 3 次失误机会与失败重试
- 5 个经过求解器和单元测试验证的可通关关卡
- 当前关卡、剩余箭头、剩余失误次数显示
- 游戏中随时重新开始

## 开发环境

- Python 3.10 或更高版本（开发测试环境：Python 3.14.3）
- Tkinter（Python 官方标准库，Windows 官方 Python 通常自带）
- 不需要安装第三方依赖

## 运行方法

```bash
python main.py
```

如果系统提示缺少 Tkinter，请安装包含 Tcl/Tk 的官方 Python 发行版。

## 测试方法

```bash
python -m unittest -v test_game.py
```

测试包括作业要求的 T01—T06，以及全部关卡的自动可解性验证。

## 操作说明

1. 在开始界面点击“开始游戏”。
2. 点击棋盘中的箭头。
3. 如果箭头前方没有其他箭头，它会飞出棋盘并消失。
4. 如果前方存在箭头，它会红色晃动，同时失误机会减 1。
5. 清空全部箭头后进入下一关；失误机会耗尽后可重新开始。
6. 游戏中可点击右上角“重新开始”恢复本关初始布局。
